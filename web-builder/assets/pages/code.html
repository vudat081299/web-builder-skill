Code block

.wb-code là primitive monospace được ship — cái mà một app với tay tới khi cần hiện lệnh, đường dẫn, khoá API hay một đoạn cấu hình. Trước đây chỉ có .demo__code của docs (chrome, không bao giờ ship). Dùng inline trên <code>/<span>, dùng khối trên <pre class="wb-code">.

Inline

Một mẩu mã giữa dòng văn: chip mono nền --wb-surface-2, viền hairline, bo --wb-radius-sm. Cỡ chữ .9em để hoà vào dòng.

Chạy python3 serve.py 8777 rồi mở đường dẫn, hoặc đặt biến --wb-font để đổi font toàn hệ.

Chạy <code class="wb-code">python3 serve.py 8777</code> rồi mở…

Khối (block)

Đặt wb-code lên <pre>: giữ nguyên khoảng trắng, cuộn ngang khi dài (thanh cuộn đã theo theme sẵn), bo góc lớn hơn. Một <code> lồng bên trong chỉ là chữ, không thành chip.

npm create vite@latest my-app
cd my-app
cp web-builder.css src/          # một file duy nhất được ship
<link rel="stylesheet" href="/src/web-builder.css">
<pre class="wb-code">npm create vite@latest my-app
cd my-app
cp web-builder.css src/</pre>
